# Logo and SEO

Current mascot: cream geometric cat on an orange rounded-square background, generated using the user reference. Integrated in the homepage/studio and browser icons. See cat-logo.md for the final prompt.

SEO includes canonical URL, descriptive title/description, Open Graph and Twitter metadata, 1200×630 social card, WebSite/WebApplication JSON-LD, sitemap and JavaScript-disabled descriptive content. No fabricated reviews or ratings. Hash routes and avatar configuration URLs share the homepage canonical. The bilingual UI shares one URL, so no misleading hreflang pages are declared.

GitHub project Pages caveat: crawlers read robots.txt at https://kimookpong.github.io/robots.txt, not the project subfolder. The bundled public/robots.txt is a template; merge its sitemap line into the root user-site robots.txt if managed separately. Submit https://kimookpong.github.io/pretty-avatar-2/sitemap.xml in Google Search Console after publishing. Public indexing and social previews can only be verified after deployment.
